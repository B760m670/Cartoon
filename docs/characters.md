# Персонажи

Каждый персонаж — папка `characters/<id>/`:

- `character.yaml` — внешность и голос (читает движок)
- `bio.md` — характер, любимые фразы, манера движения (для сценариста)

Персонажи, нужные только одному эпизоду, можно положить в `episodes/<эп>/characters/<id>/`.

## character.yaml

```yaml
name: Круг
shape: circle        # circle | square | triangle
size: 70             # «радиус» тела
color: "#FF8A3D"     # тело
outline: "#5A2E0E"   # контур
limbs: "#5A2E0E"     # руки и ноги
belly: "#FFC08A"     # пятно-животик (необязательно)
cheeks: "#FF5E7E"    # румянец (необязательно)
eye_size: 0.27       # размер глаз относительно тела
voice_pitch: 620     # высота голоса-писка, Гц
hat:                 # необязательно
  type: cap          # cap | bow | party
  color: "#3D5AFE"
```

Моргание, ходьба, мимика и открывание рта во время реплик делаются автоматически.
Новый тип внешности добавляется в `cartoon/characters.py`.
