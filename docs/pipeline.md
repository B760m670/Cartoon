# Пайплайн рендера

```
episode.yaml + scenes/*.yaml + characters/*/character.yaml
        │  loader.py — читает YAML
        ▼
   scene.py — для каждого момента t считает позы актёров (timeline.py, easing.py)
        │      рисует фон (backgrounds.py), персонажей (characters.py), реплики (drawing.py)
        │      применяет камеру и затемнения
        ▼
   кадры RGB ──► encoder.py ──► ffmpeg (H.264) ──► output/<эп>/scenes/<сцена>.mp4
   audio.py — синтез звуков (голоса-писки, «боинг» прыжка, аккорд заставки) ──┘
        ▼
   encoder.concat — склейка сцен ──► output/<эп>/<эп>.mp4 (+ музыка, если задана)
```

## Модули `cartoon/`

| Файл | Назначение |
|---|---|
| `config.py` | Пути, разрешение, fps, шрифты |
| `loader.py` | Загрузка эпизода, сцен и персонажей |
| `timeline.py` | Ключевые кадры и интерполяция |
| `easing.py` | Функции плавности (`in_out`, `back`, `bounce`…) |
| `drawing.py` | Холст в логических координатах 1280×720, облачка реплик |
| `backgrounds.py` | Фоны: `solid`, `meadow`, `night`, `image` |
| `characters.py` | Рисование персонажа: тело, глаза, рот, эмоции, руки/ноги |
| `scene.py` | Сцена: актёры, действия, камера, затемнения, звуковые события |
| `audio.py` | Синтез звуков и запись WAV |
| `encoder.py` | Вызовы ffmpeg: кодирование, склейка, музыка |
| `render.py` | Оркестрация: сцены рендерятся параллельно, затем склеиваются |
| `__main__.py` | Командная строка |

## Детали

- Рисуем с 2× суперсэмплингом и уменьшаем — края получаются гладкими.
- Все координаты в сценах — в логической системе **1280×720**; эпизод можно
  рендерить в любом разрешении (`width`/`height` в `episode.yaml`).
- Сцены рендерятся параллельно (по одной на ядро).
- Итог: MP4, H.264 (yuv420p) + AAC — открывается везде, включая телефоны и Telegram.

## Инструменты

Только открытые: Python 3.10+, Pillow, NumPy, PyYAML и ffmpeg.
Нейросетевые генераторы видео не используются — всё рисуется кодом,
поэтому результат воспроизводим и легко правится через текст.
